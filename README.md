# Inventory Optimization – EOQ & Reorder Point Analysis

## Overview

This project analyzes inventory data for multiple SKUs
and provides recommendations for inventory replenishment.

## Objectives

- Calculate Economic Order Quantity (EOQ)
- Calculate Safety Stock
- Calculate Reorder Point (ROP)
- Analyze annual ordering and holding costs
- Support data-driven inventory decisions

## Methodology

### Economic Order Quantity

EOQ = √(2DS/H)

### Reorder Point

ROP = Daily Demand × Lead Time + Safety Stock

## Tools

- Microsoft Excel
- Inventory Analytics
- EOQ Model
- Reorder Point Analysis

## Dataset

The project uses a simulated multi-SKU inventory dataset.

## Key Outputs

- EOQ for each SKU
- Safety Stock
- Reorder Point
- Annual Ordering + Holding Cost

## Business Application

The analysis can help warehouse and supply-chain teams
make better replenishment decisions and balance
inventory availability with holding and ordering costs.
